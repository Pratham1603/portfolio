# Indian Startup Funding Tracker

A weekly-updated data dashboard built to surface funding activity across the Indian startup ecosystem from 2024 onwards.

## Key Features

- **Fuzzy Search & Multi-Dimensional Filtering**: Search by startup name, sector, series (Seed, Series A/B/C), amount, and date.
- **Interactive Visualizations**: Dynamic Plotly charts for sector distribution, monthly funding velocity, and investor participation.
- **Top-Funded Leaderboard**: Ranked tables highlighting the highest funding rounds with direct source news attribution.
- **Data Export**: Clean CSV download for offline analysis and financial research.

## Tech Stack

- **Core**: Python 3.11
- **UI & Dashboard**: Streamlit
- **Data Processing**: Pandas, RapidFuzz
- **Visualization**: Plotly
