# Haulage Backend 2026

A production-grade haulage and logistics management backend system built with modern AI-first architecture.

## Key Features

- 🗺️ **AI-powered routing engine** — intelligent route optimization for haulage operations
- 📦 **Real-time tracking** — live shipment and vehicle tracking
- 🤖 **AI service integration** — intelligent recommendations and automation
- 🐳 **Dockerized microservices** — fully containerized, production-ready deployment
- 🗄️ **Prisma ORM** — type-safe database access with PostgreSQL

## Tech Stack

- **Backend**: Node.js, Express
- **AI Service**: Python, FastAPI
- **Database**: PostgreSQL + Prisma
- **Infrastructure**: Docker, Docker Compose

## Architecture

The system is split into focused services:
- `src/` — core API server
- `ai-service/` — Python-based AI microservice
- `routing-engine/` — route optimization engine
- `frontend/` — management dashboard
